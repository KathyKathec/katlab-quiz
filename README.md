# 🎮 **KatLab Quiz Game** 🎮

¡Bienvenidos al **KatLab Quiz Game**! 🎉

Este es un juego interactivo y divertido donde los jugadores pueden competir para ver quién sabe más. ¡Es el momento perfecto para desafiar tus conocimientos y pasar un buen rato!

## 🚀 **¿Cómo Jugar?**

1. **Define tu nombre**: No necesitas registrarte ni autenticarte, solo pon tu nombre para empezar.
2. **Responde las preguntas**: Cada jugador tendrá que responder una serie de preguntas lo más rápido posible.
3. **Compara tus resultados**: Después de jugar, podrás ver tus respuestas correctas y tu puntuación total.
4. **Desafía a tus amigos**: ¡Vuelve a jugar y mejora tu puntuación!

## 🎯 **Características del Proyecto**

- **Accesibilidad**: Puedes jugar desde cualquier dispositivo (móvil o computadora).
- **Competencia**: Juega contra ti mismo o desafía a tus amigos a ver quién tiene el mejor puntaje.
- **Simplicidad**: No necesitas crear una cuenta ni autenticarte, solo entra y juega.
- **Seguridad**: Los datos de cada jugador se manejan de forma segura usando **Firebase**.

- **HTML5**: Estructura básica de la página.
- **CSS3**: Estilos modernos y responsivos.
- **JavaScript**: Lógica del juego, interacción con el usuario y validación de respuestas.
- **Firebase**: Almacenamiento de datos de manera segura (aunque no hay autenticación).
